# Manga → PDF

Расширение для Chrome/Edge (MV3). Находит все страницы манги/манхвы/маньхуа на текущей странице и сохраняет в PDF.

## Установка

1. Открой `chrome://extensions`
2. Включи **Режим разработчика**
3. **Загрузить распакованное** → выбери папку `Tools/MangaToPDF-Extension`

## Использование

1. Открой главу манги на любом сайте-ридере
2. Нажми на иконку расширения → **Сканировать страницу**
3. Расширение промотает страницу (чтобы подгрузить все ленивые картинки) и покажет количество найденных страниц
4. Нажми **PDF** — будет сгенерирован PDF с каждой страницей на отдельном листе A4, full-bleed

### Ручной режим

Если автоскан не нашёл все страницы или нашёл лишнее:
- **Ручной режим** — кликай по картинкам чтобы добавить/убрать
- Shift+клик на странице — альтернативный способ

## Настройки

- **Качество** — JPEG quality (50–100%). Для архива ставь 100%, для экономии места 80%
- **Имя файла** — если оставить пустым, берётся из тайтла вкладки

## Как это работает

- `content.js` — находит контейнер с картинками, скроллит для подгрузки, собирает URL, генерирует PDF (через встроенный jsPDF) и запускает скачивание

Поддерживает `data-src` (ленивая загрузка), автоматически ищет контейнер с картинками по селекторам популярных сайтов-ридеров.
